# NoNameSha.github.io content patch

Copy these files into your al-folio repository:

- `_pages/about.md` -> replace your current homepage content.
- `_pages/cv.md` -> replace or create your CV page.
- `_bibliography/papers.bib` -> replace or merge into your current BibTeX file.
- `_news/announcement_1.md` and `_news/announcement_2.md` -> copy into `_news/`.
- `assets/pdf/cv.pdf` -> upload your PDF resume.

After copying, commit changes and wait for GitHub Actions to deploy.
